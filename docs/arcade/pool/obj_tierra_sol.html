Componentes del Escenario

• Planeta Tierra: Malla esférica con textura procedural de océanos profundos, masa continental verde esmeralda y casquetes polares.

• Atmósfera: Capa cian exterior con mezcla aditiva y sutil resplandor.

• Sol Radiante: Esfera de plasma con corona solar pulsante y luz direccional principal.

• Polvo Cósmico: Nube de 800 partículas brillantes en el fondo.

Código Modular Three.js 
// Creación del escenario Tierra y Sol 3D
const spaceGroup = new THREE.Group();

const earth = new THREE.Mesh(
  new THREE.SphereGeometry(32, 48, 36),
  new THREE.MeshStandardMaterial({
    map: makeEarthTexture(),
    roughness: 0.65
  })
);
earth.position.set(-65, -5, 0);
spaceGroup.add(earth);

const sun = new THREE.Mesh(
  new THREE.SphereGeometry(24, 32, 24),
  new THREE.MeshBasicMaterial({ color: '#ffea60' })
);
sun.position.set(95, 45, -40);
spaceGroup.add(sun);
