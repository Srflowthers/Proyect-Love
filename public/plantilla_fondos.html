Copia y pega este prompt directamente en Claude para pedirle que invente 10, 20 o 50 estilos de papel con el formato exacto que espera Proyect-Love: 

Actúa como un diseñador de interfaces y artista visual romántico. Necesito que generes estilos de papel para cartas de amor en formato JSON para el proyecto "Proyect-Love".

Cada estilo debe seguir estrictamente este esquema:
{
  "id": "slug_unico_en_minusculas",
  "name": "Nombre Poético y Evocador",
  "rarity": "comun" | "rara" | "epica" | "legendaria" | "mitica",
  "description": "Breve frase descriptiva de 1 línea de la atmósfera",
  "isBurnt": false, // true SOLO si es un pergamino milenario carbonizado con bordes quemados
  "preview": {
    "bg": "Color del Fondo (Base): puede ser un hex #RRGGBB o un radial-gradient(...) o linear-gradient(...)",
    "border": "#HexColorParaBorde",
    "textColor": "#HexColorParaTintaDeTextoRecomendada"
  }
}

REGLAS DE DISEÑO:
1. "Color del Fondo (Base)" ('preview.bg'):
   - Para estilos 'comun': tonos crema suaves, linos, marfil (#f4f0e8, #faf9f6, #fffaf0, #e8dcbf).
   - Para estilos 'rara': gradientes sutiles pastel (cielo crepuscular, sakura rosa, menta suave, lavanda).
   - Para estilos 'epica': gradientes más intensos y dramáticos (noche estelar azul profundo, papiro egipcio, terciopelo carmesí, o isBurnt: true).
   - Para estilos 'legendaria': dorados áureos (oro 24k), plata celestial, amatistas místicas y gemas.
   - Para estilos 'mitica': fondos cósmicos profundos (#000000 con centros púrpuras, carmesí o auroras con brillos).

2. "textColor": Debe tener ALTO CONTRASTE con el fondo.
   - Si el fondo es claro: usa tinta oscura (#2a1a0f, #2d2a26, #3e2723, #111111).
   - Si el fondo es oscuro: usa tinta clara o dorada (#ffffff, #fef08a, #e0e7ff, #fbcfe8).

3. "border": Color de ribete que combine con la armonía del papel.

Genera una lista JSON con [CANTIDAD] nuevos estilos únicos sin repetir IDs.
